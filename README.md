# NaifAutomation

اختبارات أسعار الأسهم باستخدام Java وSelenium وTestNG.

## التشغيل في IntelliJ

- افتح المشروع كمشروع Maven واعمل **Reload All Maven Projects** بعد تعديل `pom.xml`.
- استخدم JDK 21 أو أحدث في Project SDK وMaven Runner. الكود يستهدف Java 21.
- شغّل `testng.xml` أو نفّذ من Terminal:

```sh
mvn test
```

يتطلب تشغيل اختبارات المتصفح Chrome. قد يحتاج Selenium Manager إلى الإنترنت لتنزيل برنامج التشغيل المناسب.

## أنواع الاختبارات

- `StockSupportTest`: يتحقق من تحليل السعر وقراءة بيانات الأسهم دون شبكة أو متصفح.
- `GooglePageTest`: يستخدم Chrome وصفحات محلية لاختبار تأخر ظهور السعر واستبعاد أسعار البطاقات الأخرى.
- `StockTest`: يجلب أسعارًا حقيقية من Google Finance؛ يتأثر بتوفر الموقع والشبكة وتغير HTML وصفحات الموافقة أو التحقق.

لتشغيل اختبارات الدعم فقط:

```sh
mvn -Dtest=StockSupportTest test
```

لاختبار المتصفح محليًا دون Google:

```sh
mvn -Dtest=GooglePageTest test
```

## بيانات الأسهم

الملف `src/test/resources/stocks.xlsx`، الورقة `Sheet1`، العمود A، دون عنوان.
كل خلية غير فارغة تحتوي رمز سهم نصيًا، مثل `GOOG` أو `GOOG:NASDAQ`.
يُجرّب NASDAQ ثم NYSE عندما يؤكد الموقع أن صفحة الرمز غير موجودة، للرمز غير المحدد ببورصة.
تحديد البورصة صراحة يمنع محاولة بورصة أخرى. الملف المفقود أو الورقة المفقودة أو القائمة الفارغة أخطاء، وليست نجاحًا بلا اختبارات.

## أسباب التغييرات

- الانتظار الصريح يتحقق من نص السعر، مع إلغاء الانتظار الضمني لمنع تضارب المهل.
- محدد السعر يستهدف السعر الرئيسي؛ تغيير Google لبنية الصفحة قد يتطلب تحديثه.
- الاختبارات الحية متسلسلة لتخفيف ضغط المتصفحات والطلبات.
- استخدام هوية Chrome الفعلية، دون User-Agent قديم ثابت.
- تحميل الموارد من classpath حتى لا يعتمد التشغيل على working directory في IntelliJ.
- تحليل السعر بصيغة USD الإنجليزية ورفض النصوص المختلطة بدل حذف الأحرف وتحويلها إلى رقم خاطئ.
- إغلاق المتصفح دائمًا، وإظهار سبب الفشل، وإرفاق صورة عبر Allure مباشرة دون AspectJ.
- GitHub Actions يفشل عند فشل الاختبارات ويطبع التقارير حتى عند الفشل.

تقارير TestNG في `target/surefire-reports` ونتائج Allure في `target/allure-results`.
تشغيل `mvn test` لا يحدّث مجلد `allure-report` القديم تلقائيًا.
